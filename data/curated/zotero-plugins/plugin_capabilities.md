|variable      |class     |description |
|:-------------|:---------|:-----------|
|slug          |character |Id of the plugin; joins zotero_plugins. |
|capability_id |character |Short id of what the code can do, found by automated analysis of the release file (for example filesystem, clipboard, process-launch). |
|capability    |character |The same in words, as the plugin's card on zoteroplugins.org shows it (for example "Works with files on your computer"). |
|concern       |character |How much it matters for this plugin, as the site rates it: none, low, medium or high. The same capability can rate differently in different plugins. |
